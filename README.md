# Wort Werk

Wort Werk is a Flutter application for learning German through short, media-rich exercises.

The first release focuses on one offline article-practice exercise: learners see a noun and its image, optionally hear its pronunciation, and choose `der`, `die`, or `das`.

## Current status

The repository currently holds exercise content. Flutter application setup and implementation have not started.

See [the first-release plan](docs/first-release.md) for the agreed scope, content contract, and acceptance criteria.

## Planned local development

Once implementation begins, install Flutter and its platform tooling, connect a physical iOS or Android device, and run `flutter doctor` to verify the development environment. The exact setup steps will be added here with the Flutter project.
